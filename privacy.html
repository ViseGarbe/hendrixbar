Prima della pubblicazione: questa informativa descrive le funzioni rilevate nei file del sito. Completa i campi tra parentesi quadre e verifica con il gestore e il provider che corrispondano ai trattamenti effettivi.

2. Dati trattati e finalità

  • Dati di navigazione e log del server. Il sito è previsto su GitHub Pages, servizio di hosting statico di GitHub. GitHub dichiara che, quando si visita un sito GitHub Pages, l’indirizzo IP del visitatore viene registrato e conservato per finalità di sicurezza, anche se non si è autenticati a GitHub. Le richieste al sito possono comportare anche il trattamento di informazioni tecniche necessarie alla consegna e alla protezione del servizio. Il titolare usa queste informazioni per rendere disponibile il sito e gestire eventuali problemi o richieste di sicurezza; GitHub tratta i dati secondo la propria informativa e per le proprie finalità di servizio e sicurezza. Il sito non riceve direttamente tali log tramite il codice presente nel repository.
  • Collegamenti a servizi esterni. Il sito contiene collegamenti a Google Maps e Instagram. La connessione al servizio esterno avviene quando l’utente seleziona il collegamento; il relativo fornitore tratta i dati secondo la propria informativa. Il repository non incorpora mappe, widget o contenuti Instagram.

Il sito esaminato non contiene moduli di contatto, area utenti, prenotazioni, acquisti, strumenti di analisi o pixel pubblicitari. Se vengono aggiunti o attivati, questa informativa deve essere aggiornata prima della loro attivazione.

3. Base giuridica

Per i dati tecnici strettamente necessari a fornire le pagine richieste e mantenere la sicurezza, la base giuridica è il legittimo interesse del titolare alla gestione e protezione del sito (art. 6, par. 1, lett. f, GDPR), da bilanciare e documentare in relazione alla configurazione effettiva. Gli eventuali obblighi di conservazione o comunicazione imposti dalla legge sono trattati sulla base dell’art. 6, par. 1, lett. c, GDPR. I dati che l’utente comunica volontariamente via telefono o tramite servizi esterni sono trattati per gestire la richiesta o l’interazione avviata; titolarità, finalità e basi giuridiche di quei servizi dipendono dal caso concreto.

4. Destinatari, trasferimenti e conservazione

Il fornitore di hosting previsto è GitHub, Inc. (servizio GitHub Pages). GitHub può trattare dati tecnici per erogare e proteggere il servizio. Per ulteriori informazioni sui trattamenti effettuati da GitHub, consulta la GitHub General Privacy Statement. Il ruolo privacy di GitHub rispetto ai singoli trattamenti, le entità coinvolte, i subfornitori e gli eventuali trasferimenti internazionali dipendono dai termini del servizio e dalle configurazioni applicabili: il titolare deve verificarli nella documentazione e nei termini vigenti prima della pubblicazione.

GitHub dichiara di registrare e conservare l’indirizzo IP dei visitatori di GitHub Pages per finalità di sicurezza, ma la documentazione pubblica consultata non indica in quella pagina un termine specifico di conservazione. Non viene quindi indicato un periodo numerico per i log di GitHub Pages. Il titolare deve aggiornare questa sezione se riceve informazioni più specifiche o utilizza ulteriori servizi (per esempio un CDN o un dominio configurato tramite terzi).

5. Cookie e strumenti di tracciamento

Nel codice esaminato non risultano cookie impostati da script del sito, strumenti di analytics, pixel o altri strumenti di tracciamento. Le immagini, i fogli di stile e i font sono serviti dai file del sito; il codice non carica più Google Fonts né immagini da Unsplash. I collegamenti a Google Maps e Instagram non aprono contenuti incorporati e raggiungono tali servizi solo dopo un clic.

Questa verifica del repository non accerta i cookie o le richieste aggiunti da eventuali configurazioni di dominio/CDN o servizi di produzione. Il titolare deve controllare il sito pubblicato. Se risultano solo cookie o strumenti tecnici, va mantenuta un’informazione chiara sul loro uso; se vengono usati strumenti non tecnici, occorre acquisire un consenso valido prima di attivarli, consentire rifiuto e revoca e aggiornare l’informativa.

6. Diritti dell’interessato

Nei casi previsti dal GDPR, l’interessato può chiedere accesso, rettifica, cancellazione, limitazione o opposizione al trattamento e, quando applicabile, portabilità dei dati. Può inoltre proporre reclamo al Garante per la protezione dei dati personali. Le richieste possono essere inviate a [e-mail del titolare].

7. Natura del conferimento

I dati tecnici generati dalla navigazione sono necessari al funzionamento della comunicazione con il sito. Non è previsto nel repository un modulo che richieda all’utente di inserire dati. L’interessato può scegliere se aprire i collegamenti esterni, tenendo conto delle informative dei rispettivi fornitori.
